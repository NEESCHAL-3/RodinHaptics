# Project Status

RodinHaptics is hardware-validated source for Xiaomi POCO X7 Pro / Redmi Turbo 4
(`rodin`).

Stable behavior to preserve:

- CLICK/TICK native ID 7 path;
- Gboard typing feel;
- brightness/volume slider behavior;
- THUD/POP/HEAVY_CLICK mappings;
- generic notification/app waveform behavior;
- dynamic input-device discovery.

Not currently implemented:

- primitive composition;
- frequency profile/control;
- always-on effects;
- external control;
- synthesized two-pulse DOUBLE_CLICK.

Future changes should be hardware-tested on rodin before being merged.
